# E-Commerce Customer Segmentation & EDA (RFM-анализ)

## О проекте

Проект анализу данных интернет-магазина на основе транзакционного датасета Online Retail

## Цель проекта

Провести полный цикл первичного анализа данных: от проверки качества и подготовки данных до анализа продаж, товаров, географии и клиентской базы.
Отдельная часть проекта посвящена RFM-анализу, который используется для оценки активности и ценности клиентов.

## Цели проекта

В рамках проекта необходимо было:

* изучить структуру и качество исходных данных;
* выявить пропуски, дубликаты и аномальные значения;
* обработать возвраты и некорректные значения;
* рассчитать основные показатели продаж;
* проанализировать динамику выручки;
* изучить продажи по дням недели и часам;
* сравнить показатели по странам;
* определить наиболее значимые товары;
* оценить распределение выручки и наличие выбросов;
* провести RFM-анализ клиентской базы;
* сформулировать основные выводы по результатам анализа.

## Датасет

В работе используется датасет Online Retail, содержащий транзакции интернет-магазина.

## Основные поля:
* Поле - Описание
* InvoiceNo - номер заказа
* StockCode - идентификатор товара
* Description - описание товара
* Quantity - количество единиц товара
* InvoiceDate - дата и время заказа
* UnitPrice - цена единицы товара
* CustomerID - идентификатор клиента
* Country - страна клиента

Одна строка датасета соответствует товарной позиции внутри заказа.

## Основные этапы анализа

1. Первичный анализ данных

На первом этапе были изучены:

размер датасета;
структура и типы данных;
основные статистические показатели;
пропущенные значения;
дубликаты;
уникальные значения;
аномальные значения в количественных признаках;
операции, связанные с возвратами.

2. Предобработка данных

В процессе подготовки данных:

приведены типы данных к необходимому формату;
обработаны дубликаты;
отдельно изучены отрицательные значения Quantity, соответствующие возвратам;
для основного анализа продаж оставлены операции с положительным количеством и положительной ценой;
из даты заказа выделены год, месяц, день недели и час.

3. Основные показатели

Рассчитаны базовые показатели продаж:

общая выручка;
количество заказов;
количество клиентов;
средний чек (AOV);
общее количество проданных единиц;
среднее количество единиц товара на заказ.

4. Анализ продаж

Исследована динамика выручки во времени.
Дополнительно проведён анализ:

выручки по месяцам;
количества заказов;
продаж по дням недели;
распределения заказов по часам.
Это позволяет определить периоды с наибольшей и наименьшей активностью покупателей.

5. Географический анализ

Для стран с достаточным количеством данных рассчитаны и сравнены:

выручка;
количество заказов;
средний чек.
Отдельно рассмотрено распределение продаж между странами.

6. Анализ товаров

Проведён анализ товарного ассортимента:

топ-10 товаров по выручке;
топ-10 товаров по количеству проданных единиц;
вклад наиболее продаваемых товаров в общую товарную выручку.

При анализе ассортимента сервисные позиции (manual, postage, dotcom postage) рассматриваются отдельно и не используются как обычные товары.
Для идентификации товара используется StockCode, а Description применяется преимущественно для отображения названия товара.

7. Анализ распределения и выбросов

С помощью описательной статистики и boxplot исследовано распределение:

количества товаров в заказах;
цены единицы товара;
суммы заказа.
Отдельное внимание уделено выбросам и различию между средними и типичными значениями показателей.

8. RFM-анализ

Для клиентов с известным CustomerID проведён RFM-анализ.
Использованы три показателя:

* Recency
Количество дней с момента последней покупки клиента.
Чем меньше значение, тем недавно клиент совершал покупку.
* Frequency
Количество уникальных заказов клиента.
Чем выше значение, тем чаще клиент совершает покупки.
* Monetary
Общая сумма покупок клиента.
Чем выше значение, тем больше клиент потратил.

Для каждого показателя рассчитан балл с использованием квантильного разбиения данных.
Полученные RFM-оценки используются для сравнения клиентов по давности, частоте и сумме покупок.
RFM-анализ проводится только по операциям с известным CustomerID, поскольку транзакции без идентификатора невозможно корректно связать с конкретным клиентом.

## Основные результаты

В ходе анализа были получены следующие результаты:

* определены основные показатели продаж и клиентской активности;
* выявлена динамика выручки в рассматриваемый период;
* определены наиболее активные периоды по дням недели и времени суток;
* проведено сравнение продаж по странам;
* определены товары, формирующие значительную часть товарной выручки;
* исследованы распределения ключевых показателей и выбросы;
* рассчитаны RFM-показатели для клиентов с известным идентификатором;
* клиенты распределены по RFM-оценкам для дальнейшего анализа клиентской базы.

Более подробные числовые результаты, графики и интерпретация находятся в Jupyter Notebook.
